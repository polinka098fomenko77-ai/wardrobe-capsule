# Примірочна: вебсервіс віртуальної примірки одягу

Курсова робота. Сервіс, де користувач завантажує своє фото (або робить його камерою просто на сайті),
обирає речі з каталогу кількох магазинів і формує власний гардероб для віртуальної примірки.

## Що вже реалізовано

- Реєстрація та вхід (JWT), профіль: ім'я, нікнейм, email, мірки тіла, аватар, зміна пароля
- Фото для примірки: завантаження файлу або зйомка камерою з живими підказками
  (положення обличчя, відстань, освітлення; розпізнавання через MediaPipe Face Landmarker)
- Каталог одягу з кількох магазинів (Zara, Bershka, Stradivarius): фільтри за ціною, розміром,
  кольором і магазином, сортування, лише наявні речі
- Щоденне автоматичне оновлення каталогу (ціни, наявність розмірів, новинки, зниклі речі)
- Мій гардероб: збереження речей з каталогу
- Тема день/ніч, мови UA/EN, адаптивна верстка

У розробці: ШІ-примірка вибраної речі на фото користувача, тести.

## Структура

- `backend/`: Node.js + Express + TypeScript + Prisma
- `frontend/`: React + Vite + TypeScript
- `docker-compose.yml`: PostgreSQL
- `scripts/`: допоміжні скрипти (камера, скидання демо-даних)
- `docs/DEMO.md`: покроковий сценарій демонстрації від порожньої бази

## Запуск з нуля

1. З кореня проєкту: `docker compose up -d` (піднімає базу PostgreSQL)
2. Бекенд:
   ```
   cd backend
   npm install
   cp .env.example .env     # потім відкрийте .env і задайте JWT_SECRET
   npx prisma migrate dev
   npm run seed             # тестовий каталог: 3 магазини, 54 речі
   npm run dev
   ```
   Перевірка: http://localhost:4000/health має повернути `{"status":"ok","db":"up"}`
3. Камера (одноразово, з кореня проєкту): `bash scripts/setup-camera.sh`
   завантажує модель розпізнавання обличчя для підказок
4. В іншому терміналі:
   ```
   cd frontend
   npm install
   npm run dev
   ```
5. Відкрийте http://localhost:5173

## Корисне

- `npm run refresh` (у `backend`): оновити каталог зараз; `npm run refresh -- 1` показує, як
  він виглядатиме через добу. За розкладом оновлення відбувається щодня о 03:00 (`CATALOG_CRON` у `.env`)
- `npx prisma studio`: перегляд таблиць у браузері
- `scripts/reset-demo.sh`: скидання бази до порожнього стану для демонстрації
- Змінні середовища: `backend/.env` (шаблон у `.env.example`)

## Примітка про джерело каталогу

Магазини не мають відкритого API, тому каталог зараз наповнюється імітацією джерела
(`backend/src/catalog/source.ts`). Підключення справжнього магазину зводиться до заміни
однієї функції `fetchStoreCatalog`, решта (оновлення, ховання зниклих речей, розклад) не змінюється.
